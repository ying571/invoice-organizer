发票整理工具（Windows 便携版）

本工具离线识别根目录中的发票 PDF 和交易截图，按金额、订单号及商品信息进行配对，并为每笔可确认采购生成资料包。

使用方法
1. 解压整个工具文件夹；不要只复制“双击整理发票.cmd”。
2. 将发票 PDF 与截图直接放到工具根目录（CMD 文件所在目录），不要放到子文件夹。
3. 双击“双击整理发票.cmd”。
4. 完成后打开新生成的“整理结果”目录。

运行环境
- 支持 64 位 Windows 10/11。
- 不需要安装 Python、Microsoft Office 或 LibreOffice，也不需要联网。
- 必须保留 runtime 文件夹及其全部内容。

输入材料
- 发票：根目录中的 PDF 文件；程序读取 PDF 的第一页。
- 截图：每笔至少一张商品订单截图、支付截图或微信转账截图。
- 支持 JPG/JPEG/PNG/BMP/WEBP/TIF/TIFF 格式。
- 无法判断类型的截图不会参与配对，并会记录到待确认项。

配对与重复材料
- 程序优先按金额配对；同金额候选较多时，再参考订单号和商品名称。
- 无法唯一确认的材料不会强行配对，会列入待确认项。
- 同一张发票可使用商品订单截图和支付截图各一张；两者均无时可使用微信转账截图。
- OCR 字段完全相同的重复材料会随机选取一份参与配对，整组文件会复制到“重复文件”目录，未选中的原件仍保留在根目录。

输出内容
- 每笔生成“金额 商品简称 YYYY.MM.DD”文件夹，内含同名 PDF 和 DOCX。
- 商品简称优先取商品订单截图标题；其次为支付截图标题；仅有转账截图或无法取到截图标题时，使用发票项目名称。
- 日期优先取发票开票日期；未识别到时依次取商品订单、支付和转账截图日期。
- Word 为 A4 纵向、四边 1 cm，只包含凭证图片：有商品订单和支付两张截图时为两页；仅有其中一张或转账截图时为一页。
- 图片会等比缩放，最大高度为 23 cm。

结果目录说明
- 运行日志.txt：处理进度和配对结果；订单号仅保留末四位。
- 识别日志.json：识别字段、命名来源、配对方式与输出信息。
- 待确认.txt：无法识别或无法配对的问题，仅在有问题时生成。
- 未配对材料：待确认原件的副本。
- 重复文件：完全相同的重复材料副本。
- 若“整理结果”已存在，会自动创建“整理结果_2”“整理结果_3”等新目录，不覆盖历史结果。

原件与异常
- 原始 PDF 和截图只读取、复制，不会移动、改名或删除。
- 正常结束时会清理临时识别缓存。
- 发生未捕获异常时，工具根目录会生成“发票整理错误日志.txt”。

没有生成资料包或命令窗口提示部分材料未能配对时，请查看结果目录内的“待确认.txt”“未配对材料”和“识别日志.json”，补齐或替换材料后再运行。

第三方组件与许可见“第三方组件说明.txt”。
