发票整理工具（Windows 便携版）

使用方法：
1. 解压整个“发票整理便携版”文件夹，不要只复制 CMD 文件。
2. 将所有商品的发票 PDF 和现有交易截图放到本文件夹根目录。发票是必需材料；商品截图、支付截图至少提供一种。
3. 双击“双击整理发票.cmd”。
4. 等待窗口提示完成，然后打开新生成的“整理结果”目录。

运行过程：
1. CMD 窗口会实时显示截图识别、发票读取、配对和 Word 生成进度；单步耗时较长时每 10 秒会显示一次仍在处理的提示。
2. 每次结果目录中会生成“运行日志.txt”，记录带时间的处理过程；订单号等敏感字段保持脱敏。

输出规则：
1. 每笔资料生成一个“金额 商品简称 YYYY.MM.DD”文件夹。
2. 名称优先取商品交易截图中显示的商品标题，并自动去掉价格、规格、长度、数量等冗余内容；发票“项目名称”只用于金额校验和商品标题无法识别时的兜底，且会剥离单位、数量和单价。
3. 文件夹中包含完全同名的发票 PDF 和 Word 文件。
4. 同时有两种截图时，Word 第 1 页是商品交易截图，第 2 页是支付交易截图。
5. 只有一种截图时，Word 只生成一页并放入现有截图。
6. 日期优先取商品交易截图的“创建时间”，缺失时取支付交易截图的“创建时间”；仍缺失时取发票开票日期。
7. 原始 PDF 和截图只读取、只复制，不会移动、改名或删除。
8. 无法唯一配对的材料写入“待确认.txt”，工具不会猜测配对。

注意：
- 支持 64 位 Windows 10/11。
- 不需要安装 Python、Microsoft Office 或 LibreOffice。
- 不需要联网。
- 必须保留 runtime 文件夹及其全部内容。
